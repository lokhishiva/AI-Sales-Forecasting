# 📊 SalesCast AI – AI Sales Forecasting Dashboard

SalesCast AI is a modern **AI-powered sales forecasting dashboard** designed to analyze historical sales data, forecast future revenue, monitor product performance, and provide actionable business insights.

The project features a responsive **liquid glass / glassmorphism UI** with interactive charts and real-time dashboard updates.

---

## 🚀 Features

- 🤖 AI-powered sales forecasting dashboard
- 📈 Revenue Forecast vs Actual visualization
- 📊 Category-wise sales analysis
- 🔮 Future revenue prediction
- 🎯 Prediction accuracy monitoring
- 📦 Product-level forecast analysis
- 💡 AI-generated business insights
- 📋 Product forecast table
- 🌦️ Seasonal trend analysis
- ⚡ Interactive category filtering
- 🎨 Animated liquid glass / glassmorphism UI
- 📱 Fully responsive design
- 🌈 Animated gradient background
- 📊 Interactive charts using Chart.js

▶️ How to Run
Method 1 – VS Code Live Server
Clone or download the project.
Open the project folder in Visual Studio Code.
Make sure these files are in the same folder:
index.html
style.css
app.js
Install the Live Server extension in VS Code.
Right-click index.html.
Select:
Open with Live Server
The dashboard will open in your browser.
💻 Run Without Live Server

You can also open:

index.html

directly in a web browser.

However, Live Server is recommended during development.
